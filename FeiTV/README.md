O projeto FEItv foi desenvolvido com o objetivo de criar uma plataforma simples de streaming utilizando Java, Swing e PostgreSQL. A proposta principal do sistema foi permitir que usuários realizassem cadastro e login, pesquisassem vídeos, curtissem conteúdos e organizassem filmes e séries em listas de reprodução personalizadas. O sistema foi desenvolvido no Apache NetBeans utilizando arquitetura MVC (Model-View-Controller), além da utilização do PostgreSQL para armazenamento permanente dos dados.

O principal objetivo do projeto foi simular uma pequena plataforma de streaming semelhante a serviços como Netflix e Prime Video, permitindo a prática de conceitos importantes vistos durante a disciplina, como interface gráfica com Java Swing, conexão Java com banco de dados PostgreSQL, CRUD completo, organização de código em MVC, programação orientada a objetos e manipulação de dados em SQL.

Durante o desenvolvimento foram utilizadas diversas tecnologias. A linguagem principal utilizada foi Java, enquanto a interface gráfica foi construída utilizando Java Swing. O PostgreSQL foi utilizado como banco de dados do sistema e a comunicação entre Java e o banco foi realizada através do JDBC. O desenvolvimento foi feito no Apache NetBeans e o projeto também foi organizado utilizando GitHub para versionamento.

O sistema foi organizado em diferentes packages para separar melhor as responsabilidades de cada parte do projeto. A package “view” ficou responsável pelas telas do sistema, como Login, Cadastro e a tela principal, sendo a parte visual com a qual o usuário interage. A package “controller” foi criada para controlar as ações do sistema, recebendo as informações das telas e chamando os métodos necessários para execução das funcionalidades. Foram criados os controllers de usuário, vídeo e lista de reprodução. Já a package “dao” ficou responsável pelo acesso ao banco de dados, armazenando todas as consultas SQL utilizadas no sistema. Nela foram criados os DAOs de usuário, vídeo e lista. A package “model” foi utilizada para representar os objetos do sistema, contendo as classes Usuario, Video e ListaReproducao. Além disso, foi criada uma package responsável pela conexão com o banco, chamada “feitv”, contendo a classe Conexao.java.

O banco de dados foi desenvolvido em PostgreSQL e estruturado em tabelas responsáveis por armazenar os dados do sistema. A tabela de usuários armazena nome, usuário e senha dos usuários cadastrados. A tabela de vídeos armazena informações como título, descrição, tipo e quantidade de curtidas. Também foram criadas tabelas responsáveis pelas listas de reprodução e pela relação entre listas e vídeos, permitindo adicionar vários vídeos em diferentes listas.

Entre as funcionalidades implementadas no sistema, a primeira foi o cadastro de usuários, permitindo criar contas diretamente pela interface gráfica. Em seguida foi implementado o sistema de login, no qual o usuário informa seu nome de usuário e senha para acessar o sistema. Após o login, o usuário é direcionado para a tela principal, onde consegue pesquisar filmes e séries pelo nome. Os resultados da pesquisa são exibidos em uma JTable conectada diretamente ao banco de dados.

Também foi implementado um sistema de curtidas e descurtidas, permitindo aumentar ou diminuir a quantidade de curtidas dos vídeos armazenados no banco. Outra funcionalidade importante foi o gerenciamento de listas de reprodução. O usuário consegue criar listas, editar o nome, excluir listas, adicionar vídeos, remover vídeos e visualizar todos os vídeos presentes em determinada lista. Além disso, foi implementada a funcionalidade de favoritos, integrada diretamente às listas de reprodução. Quando o usuário clica em favoritar, o vídeo é adicionado a uma lista já existente.

A interface gráfica foi personalizada utilizando um tema escuro inspirado em plataformas reais de streaming. Foram utilizadas cores escuras, botões personalizados, tabelas estilizadas, fontes modernas e ícones para melhorar a aparência visual do sistema. O objetivo foi deixar o projeto mais agradável visualmente e mais próximo de uma aplicação profissional.

Durante o desenvolvimento do projeto algumas dificuldades foram encontradas, principalmente relacionadas à conexão com PostgreSQL, manipulação de ResultSet, organização em MVC, funcionamento das listas de reprodução e integração entre JTable e banco de dados. Também houve dificuldades relacionadas à estilização visual utilizando Java Swing. Grande parte do desenvolvimento envolveu testes, correção de erros e reorganização da estrutura do sistema.

Com o desenvolvimento do FEItv foi possível aprender diversos conceitos importantes para o desenvolvimento de software, como funcionamento da arquitetura MVC, conexão Java com PostgreSQL, utilização de PreparedStatement, manipulação de ResultSet, criação de interfaces gráficas, separação de responsabilidades e desenvolvimento de CRUD completo. Além disso, o projeto ajudou a melhorar a organização do código e a compreensão sobre aplicações conectadas a banco de dados.

Por fim, o projeto FEItv conseguiu atingir os objetivos propostos, entregando um sistema funcional de streaming com autenticação, gerenciamento de vídeos e listas de reprodução. Além do funcionamento correto das funcionalidades, o projeto proporcionou aprendizado prático sobre desenvolvimento desktop em Java, banco de dados PostgreSQL e organização de sistemas utilizando arquitetura MVC.
